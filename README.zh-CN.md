**一个只给你一个人工作、跑在你自己电脑上的新闻编辑部。**

本地优先、意图驱动的个人新闻软件，for macOS。

## 为什么做这个

所有新闻软件都按**标签**来做个性化：你勾「科技」「政治」「体育」，
勾一样的人看到的东西一模一样。

但人追新闻不是这么追的。你要的不是「政治」——
你想知道的是*某个人这周具体干了什么*、*那场谈判到底动了没有*、
*你真正在意的那件事，相比昨天有什么新进展*。

personal-newsroom 把你会说出口的那句话，变成个性化的基本单位。

## 它做什么

| | |
|---|---|
| **今日** | 专属于你的今日摘要，加一个**「昨天到今天」**板块：你关注的事，到底变了什么 |
| **快讯** | 短平快的最新动态，只推过了你意图闸门的 |
| **阅读** | 一个真正的阅读器。正文抽取出来直接在软件里读，不用跳到浏览器 |
| **关注** | 勾一个预置标签，或者自己写一句话。无论哪种，**它怎么帮你找的，你都看得见、改得动** |
| *按需* | 任意一条新闻都有「深入」按钮：现场生成一份带时间线的内容总结，**每一句都能点回原文的那一段** |

**三个不一样的地方：**

1. **不只是标签，是意图。** 预置标签有，一键就能勾。但上限是你自己写的那句话，
   而且系统把它的判断逻辑摊开给你看，不藏在黑箱里。
2. **一切都在你自己机器上。** SQLite 存在你硬盘，你自己的 API key，不用注册，
   没有我们运营的服务器。备份就是拷一个文件夹。
3. **它告诉你什么是*新的*。** 不是每天早上把同一件事重新摘要一遍，
   而是「自从上次跟你说过之后，这件事动了什么」。

## 诚实的能力边界

装之前就该知道。

- **只支持 macOS。** 后台调度、通知、打包都建在 launchd / `SMAppService` 上。
  不支持 Windows 和 Linux，也不打算抄诺。
- **社交媒体源是单独的 63 MB 下载。** 微博、B站、知乎、小红书、X 都不提供 RSS，
  要靠 RSSHub 转换，它装好有 370 MB，所以不随应用一起发。在设置里一键启用，
  或者填你自己已有的实例地址。**Telegram 是自己实现的，开箱即用。**
- **Twitter/X 需要你自己提供一份 cookie。** 现在已经没有零配置的免费方式读 X 了。
  你要么提供登录后的 web cookie，要么付费买抓取服务。
- **本地存储 ≠ 完全离线。** 数据在你硬盘上，但发给 AI 服务商的内容确实出网了。
  接 Ollama 的完全离线模式在计划内；它更慢、质量更差，我们会照实说。
- **付费墙就是付费墙。** 抓不到正文时阅读器会明说，并提供「在浏览器打开」。
  **不会拿摘要冒充原文。**
- **软件界面本身现在只有中文。** 每个关注的**内容**输出语言是可以自由设置的
  （摘要、快讯用什么语言写），但界面外壳（菜单、设置项这些文字）还没做多语言。

## 许可证

**AGPL-3.0。** 这是个给「想自己拥有数据的人」用的工具，
所以用了能保证这一点的许可证——**没人能拿走它再做成一个闭源云服务卖回给你**。

同时这也让我们能直接内置 [RSSHub](https://github.com/DIYgod/RSSHub)（同为 AGPL-3.0），
这正是 Telegram、微博、B站这些不用你装 Docker 就能用的原因。

## 它从哪来

本项目从 `daily-brief` 引出——那是一个双语 AI 新闻门户，每天给所有读者出同一份报纸。
它的管线很好：证据收集、带交叉验证的事件聚类、引用绑定到真实来源的两阶段写作——
但它服务的是一群读者，不是一个人。
personal-newsroom 保留这条管线，把它上面的一切围绕单个读者重建。
